# CarbonSense

**Vertical**: Environmental Awareness / Personal Carbon Tracking  
**Aesthetic**: Dark, editorial, scientific (Bloomberg Terminal meets environmental NGO)
**Made with Antigravity**

CarbonSense is a production-grade, highly interactive carbon footprint tracking, awareness, and reduction platform. It enables users to calculate their footprint across multiple categories, view visual benchmarks using Google Charts, simulate hypothetical lifestyle changes in real-time, and get personalized, structured tips generated by the **Gemini 2.0 Flash API**.

---

## Tech Stack & Rationale

*   **Next.js 14 (App Router)**: Offers optimized server-side rendering for API routes, client-side routing, and native font/image loading optimizations.
*   **Tailwind CSS**: Provides rapid utility-based styling to implement our custom editorial design system without writing monolithic CSS files.
*   **Google Charts**: A highly robust, performant, and standard library for data visualizations, loaded dynamically via secure scripts.
*   **Gemini 2.0 Flash API**: High-speed, structured JSON output generation to deliver personalized carbon reduction advice from a carbon expert.
*   **Framer Motion**: Enables smooth transitions and micro-animations to create a premium, reactive interface.
*   **canvas-confetti**: Lighthearted reward mechanism triggered on achieving completion goals (50% and 100%).

## Emission Factors & Sources

All calculations are modeled on values derived from the **Intergovernmental Panel on Climate Change (IPCC)** and **Our World in Data** standards:

| Category | Input / Activity | Emission Factor | Assumed Standard / Source |
| :--- | :--- | :--- | :--- |
| **Transport** | Car driving | `0.21 kg CO₂ / km` | Avg passenger vehicle emissions |
| | Public transit | `1.20 kg CO₂ / hour` | Average bus/rail occupancy emissions |
| | Flights (Economy) | `0.255 kg CO₂ / km` | IPCC short/medium haul economy emissions. Avg 1,000 km per flight. |
| | Flight Class Multipliers | Business: `1.5x`, First: `2.0x` | Standard seat footprint allocation |
| **Energy** | Electricity (India Grid) | `0.82 kg CO₂ / kWh` | Central Electricity Authority (CEA) India grid factor |
| | Gas usage | `2.04 kg CO₂ / m³` | Natural gas combustion factor |
| | House size heating/cooling | `5.00 kg CO₂ / m² / yr` | Standard HVAC overhead estimation |
| **Food & Diet** | Meat-heavy diet | `3,300 kg CO₂ / yr` | High-meat diet consumer avg |
| | Average balanced diet | `2,500 kg CO₂ / yr` | Standard omnivorous consumer avg |
| | Vegetarian diet | `1,700 kg CO₂ / yr` | Dairy & plant-based consumer avg |
| | Vegan diet | `1,500 kg CO₂ / yr` | Purely plant-based consumer avg |
| | Food waste multipliers | Low: `0.9x`, Medium: `1.0x`, High: `1.2x` | Waste mitigation modifier |
| | Local Produce discount | Up to `-10%` on Food | Food-miles transportation discount |
| **Lifestyle** | Online shopping | `3.50 kg CO₂ / order` | Average courier delivery packaging/fuel footprint |
| | Video Streaming | `0.036 kg CO₂ / hour` | Data center and local hardware power emissions |
| | Clothing purchases | `14.50 kg CO₂ / item` | Average fabric production & logistics emissions |
| | Recycling discount | Yes: `-250 kg`, Partial: `-100 kg` | Landfill deflection credit |

## Local Setup

### 1. Clone & Install
```bash
git clone https://github.com/vedant-B22/Carbonsense.git
cd Carbonsense
npm install
```

### 2. Configure Environment Variables
Create a `.env.local` file in the root directory:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Deployment

### Deploy to Vercel (Recommended)
1. Push to GitHub.
2. Link your repository in Vercel.
3. Configure the `GEMINI_API_KEY` under Settings -> Environment Variables.
4. Deploy!

### Deploy to Firebase Hosting
1. Build the production build: `npm run build`
2. Initialize Firebase: `firebase init hosting` (Choose your build folder `out` or configure next.js experimental integrations)
3. Deploy: `firebase deploy`

## Assumptions Made

1. **Flight Distance**: Since the input is "flights/year", we assume an average distance of 1,000 km per flight.
2. **Public Transit Speed**: Assumes an average speed of 30 km/h under standard occupancy to convert travel hours to distance-equivalent carbon output.
3. **House Size HVAC**: Standard base heating/cooling emissions are calculated at 5 kg CO₂/m²/year to account for thermal space requirements regardless of monthly electricity bills.
4. **Food Miles**: Eating local reduces diet footprint by a maximum of 10%, aligning with studies that show logistics makes up about 10-15% of food emissions.
